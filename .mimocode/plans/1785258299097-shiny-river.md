# Plan: Completar i18n — Catalog.tsx y ProductCard.tsx

## Contexto

El otro modelo construyó un sistema i18n completo con diccionarios español/inglés.
La mayoría de componentes ya usan `t()`, pero dos componentes clave tienen
strings hardcodeados en español:

1. **Catalog.tsx** (270 líneas) — TODOS los filtros, chips, ordenación, empty state
2. **ProductCard.tsx** — labels de specs ("Peso", "Balance", "Tamis")

Las keys del diccionario ya existen en ambos idiomas. Solo hay que conectarlas.

---

## Cambio 1: Catalog.tsx

**Archivo:** `src/components/Catalog.tsx`

Añadir import de `useLocale` y reemplazar todos los strings hardcodeados:

| Hardcodeado | Key del diccionario |
|---|---|
| `"Filtros"` | `t("catalog.filtros")` |
| `"Búsqueda de precisión"` | `t("catalog.busquedaPrecision")` |
| `"Buscar marca o modelo..."` | `t("catalog.placeholderBusqueda")` |
| `"Marca"` | `t("catalog.marca")` |
| `"Todas"` | `t("catalog.todas")` |
| `"Nivel"` (filter title) | `t("catalog.nivelLabel")` |
| `"Estilo de juego"` (filter title) | `t("catalog.estiloLabel")` |
| `"Forma"` (filter title) | `t("catalog.forma")` |
| `"Precio máximo: X €"` | `t("catalog.precioMaximo", { n: maxPrice })` |
| `"Limpiar todo"` | `t("catalog.limpiarTodo")` |
| `"palas"` / `"raquetas"` | `t("catalog.cuentaPalas")` / `t("catalog.cuentaRaquetas")` |
| `"Más recientes"` | `t("catalog.ordenar.recientes")` |
| `"Precio: menor a mayor"` | `t("catalog.ordenar.precioAsc")` |
| `"Precio: mayor a menor"` | `t("catalog.ordenar.precioDesc")` |
| `"No hay resultados con esos filtros."` | `t("catalog.noResultados")` |
| `"Limpiar filtros"` | `t("catalog.limpiarFiltros")` |
| Level chip labels (hardcoded array) | `t("catalog.nivel.principiante")` etc. |
| Style chip labels (hardcoded array) | `t("catalog.estilo.control")` etc. |
| Shape chip labels (hardcoded array) | `t("catalog.formaPala.redonda")` etc. |
| Emoji `🎾` en empty state | Eliminar (gpt-taste) |

**Implementación:**
- Añadir `import { useLocale } from "@/i18n/LocaleContext"` 
- `const { t } = useLocale()` dentro del componente
- Los arrays LEVELS, STYLES, SHAPES se convierten en funciones que reciben `t`
- El placeholder del input usa `t("catalog.placeholderBusqueda")`
- El precio máximo usa interpolación: `t("catalog.precioMaximo", { n: maxPrice })`

**Nota sobre `catalog.precioMaximo`:** La key es `"Precio máximo"` / `"Max price"` (sin
valor). Se implementa como:
```tsx
<FilterGroup title={`${t("catalog.precioMaximo")}: ${maxPrice} €`}>
```
