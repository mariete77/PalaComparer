# Plan: Completar fotos de producto con Firecrawl

## Contexto

53 de 79 productos no tienen foto real (solo 32.9% cobertura). Los productos
que faltan son mayoritariamente palas de pádel de marcas como Adidas, Head,
Bullpadel, Drop Shot, Royal Padel, Siux, Kombat, Akkeron, StarVie, etc.

**Dato clave:** 78 de 79 productos ya tienen URLs de tienda (de los scrapers
de precios). Esto significa que podemos usar Firecrawl para visitar esas
páginas y extraer la imagen del producto directamente.

---

## Pipeline existente

```
scripts/image-sources.json  →  URL por producto (plantilla)
        ↓
scripts/import-images.mts   →  descarga + escribe real-images.json
        ↓
src/data/real-images.json   →  manifiesto que usa la app
```

Solo falta rellenar las URLs vacías en `image-sources.json`.

---

## Script nuevo: `scripts/scrape-images-firecrawl.ts`

Para cada producto sin imagen:
1. Busca su URL de tienda en `real-offers.json` (Amazon) o `real-offers-stores.json` (Firecrawl stores)
2. Usa Firecrawl `/scrape` con `formats: ["markdown"]` para extraer `og:image` del metadata
3. Escribe la URL encontrada en `scripts/image-sources.json`
4. Si no encuentra imagen en una tienda, prueba la siguiente

**Prioridad de fuentes:**
1. PadelNuestro (tienda especializada, buenas fotos)
2. Amazon (fotos de alta calidad)
3. Otras tiendas (PádelPoint, StreetPadel, etc.)

**Extracción de imagen:**
- Buscar en metadata: `og:image`, `og:image:secure_url`
- Fallback: primera imagen grande del markdown (regex `<img.*src="(...)"`)

**Rate limiting:**
- Reutilizar la lógica de `scrape-firecrawl.ts` (11 peticiones/min)
- 2 créditos por producto (map + scrape), o 1 si ya tenemos la URL

---

## Ejecución

```bash
# 1. Ejecutar el scraper de imágenes
FIRECRAWL_API_KEY=fc-... npx tsx scripts/scrape-images-firecrawl.ts

# 2. Revisar las URLs encontradas en image-sources.json

# 3. Descargar las imágenes
npm run import:images

# 4. Verificar en dev
npm run dev
```
